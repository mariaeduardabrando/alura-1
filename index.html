4. Boas Práticas de Segurança da Informação

  • Use senhas fortes: mínimo 12 caracteres, misturando maiúsculas, minúsculas, números e símbolos.
  • Nunca reutilize senhas entre serviços diferentes.
  • Ative autenticação em dois fatores (2FA) sempre que possível.
  • Armazene senhas com hash + salt (bcrypt, Argon2).
  • Use HTTPS para proteger dados em trânsito.
  • Mantenha sistemas atualizados para evitar vulnerabilidades conhecidas.
  • Princípio do menor privilégio: conceda apenas as permissões necessárias.
  • Limite tentativas de login para dificultar ataques de força bruta.
